# doti

> Currently under development.

`doti` is a new dotfile manager.

## Features
- Configure dotfile locations
- Import dotfiles into local folder.
- Export dotfiles to remote folders.
- Protect selected dotfiles with `age` compatible encryption.

Things doti doesn't support
- Git integration
- Cloud backup

## Manual
```
doti
doti init
doti add <item-name>
doti import
doti export
```
